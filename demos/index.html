Live demos

The same admin application, built twice: once with Angular Material and once with Tailwind. Both read from a public Supabase project, so you can click through the lists, the forms and the CRUD pages.

Pick a UI layer

  • Angular Material

    @pidrang/material renders ResourceTable and ResourceForm on Angular Material and Signal Forms.

    Open the Material demo↗ (opens in a new tab)

  • Tailwind

    @pidrang/tailwind exposes the same components, styled with Tailwind utility classes.

    Open the Tailwind demo↗ (opens in a new tab)

Both layers share one component API: switching is a change of import and of element name.

What is in the demo

  • Three resources: users, products and orders. Each has a list, a show page, a create form, an edit form and delete.
  • Reads are open to everyone. Create, edit and delete ask you to sign in first.
  • The data is reset every hour, so break it as much as you like.

Build the same in your app

The demos use the published packages and the same three steps as the guide: install, generate the resources with npx pidrang init, then wire the routes and the providers.
