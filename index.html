Pidrang

Build Angular admin applications faster.

An open-source, headless framework for admin panels, dashboards and internal tools. Signal-first, with Supabase and two UI adapters, Angular Material and Tailwind. Requires Angular 22.

Get started

npm install @pidrang/core @pidrang/supabase @pidrang/material
npx pidrang init
Read the quickstart npm packages GitHub repository
