Pidrang

Build Angular admin applications faster.

An open-source, headless framework for Angular admin panels, dashboards and internal tools. Describe a table once and get the list, the forms and the CRUD pages.

Less boilerplate for every table

  • Describe a table once. A typed Resource lists its fields; ResourceTable and ResourceForm render the table and the form from it.
  • Angular-native. Signals, resource(), Signal Forms and standalone APIs. List state is signals: value(), isLoading(), error(), reload().
  • Headless core. @pidrang/core depends on @angular/core only. Angular Material and Tailwind layers share one component API.
  • Supabase in a few commands. npx pidrang init reads your Supabase schema and writes the resources and the CRUD pages, without overwriting a file. Authorization stays in your Row Level Security policies.

One definition per table

import { Resource } from '@pidrang/core';

export const resources: Resource[] = [
  {
    name: 'products',
    fields: [
      { name: 'id', type: 'text', readOnly: true },
      { name: 'name', type: 'text' },
      { name: 'price', type: 'number' },
      { name: 'in_stock', label: 'In stock', type: 'boolean' },
      {
        name: 'created_at',
        label: 'Created at',
        type: 'timestamp',
        readOnly: true,
        hasDefault: true,
      },
    ],
  },
];

The table and the create and edit forms are rendered from these fields. pidrang init can generate it from your schema.

Get started

npm install @pidrang/core @pidrang/supabase @pidrang/material @supabase/supabase-js
ng add @angular/material
npx pidrang init

Run in an Angular 22.1+ standalone app. pidrang init connects to your Supabase project, generates the resources and pages, and prints the routes and providers to paste. Every table needs an id primary key.

Packages

@pidrang/core
Contracts, providePidrang and signal-based state. Depends on @angular/core only.
@pidrang/supabase
DataProvider and AuthProvider backed by Supabase.
@pidrang/material
ResourceTable and ResourceForm on Angular Material and Signal Forms.
@pidrang/tailwind
The same components styled with Tailwind utility classes.
pidrang
The CLI: npx pidrang init scaffolds resources and CRUD pages from a Supabase schema.

Open source

Pidrang is MIT licensed and pre-1.0: the public API may change between minor versions. It is inspired by the resource and data-provider architecture of Refine, and is not affiliated with Angular or Refine.

Planned, not available yet: REST and GraphQL data providers, a PrimeNG UI layer, Tailwind pages from the CLI. See the roadmap.
