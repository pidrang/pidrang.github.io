Get started

  1. Install

    In an Angular 22.1+ standalone app:

    npm install @pidrang/core @pidrang/supabase @pidrang/material @supabase/supabase-js
ng add @angular/material

  2. Generate

    From the root of the app, connect to your Supabase project and pick your tables. The CLI writes resources.ts and the List, Create, Show and Edit pages, without overwriting a file.

    npx pidrang init

  3. Wire

    Paste what the CLI prints: ...resourceRoutes in your routes, provideRouter(routes, withComponentInputBinding()) and providePidrang in your app config. Then run ng serve.

Every table needs an id primary key. Read the full guide
